О проекте ThreadsSorting

Что это?

Django-приложение, демонстрирующее многопоточную сортировку с визуализацией прогресса в реальном времени. При открытии дашборда запускаются 4 потока, каждый из которых сортирует один и тот же случайный список своим алгоритмом.

Алгоритмы

  • Bubble Sort — сортировка пузырьком (O(n²))
  • Insertion Sort — сортировка вставками (O(n²))
  • Quick Sort — быстрая сортировка (O(n log n) в среднем)
  • Monitor — имитация фонового мониторинга

Как это работает?

  • Бэкенд запускает каждый алгоритм в отдельном daemon-потоке
  • Состояние каждого потока хранится в глобальном словаре с защитой через threading.Lock
  • Фронтенд опрашивает API каждые 500мс и обновляет прогресс-бары в реальном времени

Технологии

  • Python 3.x
  • Django 5.2.18
  • Threading — модуль потоков Python
  • JavaScript Fetch API — для AJAX-запросов
